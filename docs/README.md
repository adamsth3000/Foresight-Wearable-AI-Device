# Documentation Index

This folder contains the non-code project foundation for the Foresight repository.

The documentation intentionally distinguishes between:
- current implemented state
- planned architecture
- future concepts

Planned capabilities described here are architectural direction, not completed functionality.

## Sections
- `architecture/`: long-term system architecture, phase planning, boundaries, abstractions, and data concepts.
- `development/`: setup instructions, testing workflow, roadmap, and contributor expectations.
- `project-state/`: current implemented state, decisions, changelog, backlog, and next recommended task.
