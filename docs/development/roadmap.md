# Development Roadmap

## Current Implemented State
The repository is in a documentation and scaffold phase. The roadmap below describes intended sequencing, not completed functionality.

## Near-Term Sequence
1. Strengthen durable architecture and project-state documentation.
2. Keep the Python scaffold, configuration, and tests healthy.
3. Define the first implementation milestone within the Lab phase.
4. Introduce implementation packages only when that milestone requires them.

## Phase-Oriented Outlook

### Lab Preparation
- clarify capture, replay, and debugging goals
- define the first development workflow boundaries

### Field Preparation
- define how live sessions and post-processing should relate
- plan for structured recording without implementing integrations prematurely

### Intelligence Preparation
- define durable subsystem boundaries before writing feature-heavy code

### Wearable Preparation
- preserve adapter-oriented architecture so future wearable hardware is an extension rather than a rewrite
